PFX / P12 to PEM Converter

Drop in a password-protected .pfx or .p12 file to split it into a certificate, private key, and CA chain as separate .pem files. Works with both modern and legacy PKCS#12 encryption.

Drop a .pfx or .p12 file here, or click to choose
PKCS#12 files (.pfx, .p12)

How this works: this page loads a JavaScript cryptography library (node-forge, self-hosted on this page — no CDN) and decrypts your file directly in this browser tab. The file, your password, and the private key it contains are never sent to any server; nothing is uploaded.

Compatibility: handles both the modern default OpenSSL 3.x PKCS#12 encryption (AES) and the older legacy encryption (RC2/3DES) used by many existing Windows- and IIS-exported certificates.
